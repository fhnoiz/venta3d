VENTA3D PRO — PWA PARA ANDROID

Esta versión está preparada para instalarse como aplicación desde Google Chrome.

IMPORTANTE:
- No abras index.html directamente desde el administrador de archivos si quieres instalarla como PWA.
- Debe estar publicada en una dirección HTTPS.
- Una vez publicada: abre el enlace en Chrome -> menú ⋮ -> Instalar aplicación / Agregar a pantalla de inicio.
- El botón "Instalar" dentro de Venta3D Pro funcionará cuando Chrome entregue el aviso de instalación.

ARCHIVOS:
- index.html: aplicación completa
- manifest.json: configuración PWA
- sw.js: funcionamiento offline/cache
- icon-192.png / icon-512.png: iconos
- favicon.png: icono del navegador

PUBLICACIÓN GRATIS:
Puedes subir esta carpeta a GitHub Pages, Netlify o Cloudflare Pages. El enlace final debe comenzar por https://
